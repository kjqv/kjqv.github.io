Signups from a photo

Reading handwriting (and quick actions it doesn't recognize) uses Claude, with your own Anthropic API key (about a cent a photo, billed to you). It's saved only on this phone and only ever sent to Anthropic.

In Photos, open the picture of the sheet, press and hold on the writing, tap Copy All, then paste it here. One signup per line works best: Name – Song – Artist.

Live Text doesn't see cross-outs, so untick anyone who's done (anyone already in the queue or sung tonight is caught for you). Prefer Claude reading the photo itself? Options → KJ view: signup sheet.
